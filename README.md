# Emety — site institucional
React + Vite + Tailwind CSS.
- `npm install` · `npm run dev` (local) · `npm run build` (produção) · `npm run preview`
- Conteúdo: `src/data/content.js` · Seções: `src/components`
- Antes de publicar: troque `emety.com` pelo domínio real em `index.html`, `public/robots.txt` e `public/sitemap.xml`; troque `contato@emety.com` em `Contact.jsx` e `Footer.jsx`; substitua os `[PLACEHOLDER]` de `content.js`.
- Deploy: Vercel (preset Vite, configurado em `vercel.json`).
